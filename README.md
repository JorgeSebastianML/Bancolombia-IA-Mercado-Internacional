# Bancolombia-IA-Mercado-Internacional
Scraping y análisis de para noticias internacionales 


## Estructura del Proyecto

## Instalación

1. Clona el repositorio:
    ```sh
    git clone https://github.com/tu_usuario/Bancolombia-IA-Mercado-Internacional.git
    cd Bancolombia-IA-Mercado-Internacional
    ```

2. Instala las dependencias:
    ```sh
    pip install -r Scraping_news/requirements.txt
    ```

## Uso

### Scraping de Noticias

El script principal para realizar el scraping de noticias se encuentra en [main.ipynb](http://_vscodecontentref_/7). Para ejecutar el scraping:

1. Abre el archivo [main.ipynb](http://_vscodecontentref_/8) en Jupyter Notebook o Jupyter Lab.
2. Define la lista de búsqueda y otros parámetros necesarios.
3. Ejecuta las celdas para realizar el scraping y guardar los resultados.

### Análisis de Sentimiento

El análisis de sentimiento se realiza en el archivo [sentiment_analisys.ipynb](http://_vscodecontentref_/9). Para ejecutar el análisis:

1. Abre el archivo [sentiment_analisys.ipynb](http://_vscodecontentref_/10) en Jupyter Notebook o Jupyter Lab.
2. Ejecuta las celdas para cargar los datos, procesarlos y realizar el análisis de sentimiento.

### Métricas

Para calcular y visualizar las métricas del análisis, utiliza el archivo [metrics.ipynb](http://_vscodecontentref_/11):

1. Abre el archivo [metrics.ipynb](http://_vscodecontentref_/12) en Jupyter Notebook o Jupyter Lab.
2. Ejecuta las celdas para calcular las métricas y visualizar los resultados.

## Archivos Principales

- [analisis.ipynb](http://_vscodecontentref_/13): Contiene el análisis principal de los datos de precios y noticias.
- [metrics.ipynb](http://_vscodecontentref_/14): Calcula y visualiza las métricas del análisis de sentimiento.
- [sentiment_analisys.ipynb](http://_vscodecontentref_/15): Realiza el análisis de sentimiento de las noticias.
- [main.ipynb](http://_vscodecontentref_/16): Script principal para realizar el scraping de noticias.
- [news_analisis.py](http://_vscodecontentref_/17): Contiene las funciones para analizar las noticias.
- [scraping.py](http://_vscodecontentref_/18): Contiene las funciones para realizar el scraping de noticias.
